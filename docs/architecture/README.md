# Architecture Documentation (Live Architecture)

This directory contains the live architecture documentation for the **Alfabra Vector** using **Structurizr DSL** and **Structurizr Lite**.

## How to get started

1. **Run Structurizr Lite**
   ```bash
   docker compose up -d structurizr
   ```
   The UI will be available at <http://localhost:8080>.

2. **Edit DSL files**
   - All DSL files are under `docs/architecture/views/`.
   - The master `workspace.dsl` includes each view via `!include` statements.
   - Changes are hot‑reloaded – simply refresh the browser.

3. **Export diagrams**
   ```bash
   ./scripts/export.sh
   ```
   The generated PNG, SVG, and PlantUML files are stored under `exports/`.

4. **Validate DSL**
   ```bash
   ./scripts/validate.sh
   ```

5. **Generate documentation**
   ```bash
   ./scripts/generate-docs.sh
   ```
   (future step – will produce a static site with diagrams.)

## Folder layout

```
architecture/
├─ workspace.dsl          # Master workspace definition
├─ README.md              # This file
├─ adr/                   # Architectural Decision Records
├─ exports/               # Generated diagram artifacts (png, svg, plantuml)
├─ views/                 # Individual C4 view DSL files
└─ scripts/               # Helper scripts for export/validation
```

## Conventions

- Follow the C4 model naming conventions.
- Keep each view in its own `.dsl` file for modularity.
- ADRs are numbered sequentially (`0001-...`).
- All diagrams are version‑controlled in Git.

## CI/CD Integration (future)

- The generated artifacts can be published as part of documentation site builds.
